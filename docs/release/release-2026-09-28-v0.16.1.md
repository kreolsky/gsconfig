# Release v0.16.1 — 2026-09-28

The first tagged release of gsconfig: 3 commits since `master`. It fixes several runtime bugs,
adds an offline test suite and changes how the library is distributed: it is installed
from git tags instead of PyPI.

## Fixes

- A document's page iteration no longer crashes: `pages` is used as a property everywhere.
- Parser params passed to one `Page`/`Document` no longer leak into the next one through a
  shared mutable default.
- Printing a `Page` no longer makes a network request to Google Sheets.
- An unknown `parser_version` is rejected when a document or page is created, not later at
  parse time.
- Extractor parser caching now keys params consistently, so pages with the same params reuse
  one converter.
- Faster template rendering and CSV export: regexes are compiled once, the CSV writer is
  created once per file.

## Distribution

- The name `gsconfig` on PyPI belongs to an unrelated project; this library is not published
  there. Install a release by tag:
  `pip install git+https://github.com/kreolsky/gsconfig@v0.16.1`
- CI runs the test suite (converter golden cases under `v1` and `v2`, template engine) on
  every push to `dev`/`master`.

# Upgrade actions

- If you ran `pip install gsconfig`, you got the unrelated GeoServer package. Uninstall it
  and install from the git tag above.
- `python setup.py publish` is removed; build with `python -m build` if you need a wheel.
- No changes to parse or render output for existing spreadsheets and templates, no changes
  to params, defaults or public names.
