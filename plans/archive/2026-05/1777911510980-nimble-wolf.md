## Приоритет 1 — Баги (критические)

### 1.1. РЕГРЕССИЯ итерации 1: `_get_parser` крашится на нехэшируемых params

**Файл**: `gsconfig/extractor.py:19`

`hash(frozenset(params.items()))` падает, когда `params` содержит нехэшируемые значения:
- `params['schema']` может быть `dict` (complex schema) — `frozenset` крашится
- `params['key_skip_letters']` — `set`, тоже нехэшируемый

**Фикс**: Заменить хэширование на безопасное. Вариант — сериализовать в строку:

```python
def _get_parser(self, params):
    params_key = str(sorted(params.items()))
    if self._cached_parser is None or self._cached_parser_params_key != params_key:
        self._cached_parser = gsparser.ConfigJSONConverter(params)
        self._cached_parser_params_key = params_key
    return self._cached_parser
```

### 1.2. `Document.save(mode='full')` вызывает `self.pages()` — генератор не вызываем

**Файл**: `gsconfig/gsconfig.py:311`

```python
pages = self.pages() if mode == 'full' else self
```

`self.pages` — это `@property`, возвращающий генератор. Вызов `self.pages()` попытается вызвать генератор как функцию → `TypeError: 'generator' object is not callable`.

**Фикс**: Убрать `()`:
```python
pages = self.pages if mode == 'full' else self
```

## Приоритет 2 — Mutable Default Arguments (Python antipattern)

### 2.1. `params: dict = {}` в конструкторах

**Файлы**: 
- `gsconfig/gsconfig.py:325` — `GameConfigLite.__init__(params: dict = {})`
- `gsconfig/gsconfig.py:365` — `GameConfig.__init__(params: dict = {})`
- `gsconfig/gsparser.py:392` — `ConfigJSONConverter.__init__(params={})`

Mutable default argument — один и тот же dict шарится между всеми вызовами. Если один вызов мутирует dict, следующий получит изменённый.

**Фикс**: Заменить на `None` с проверкой:
```python
def __init__(self, ..., params: dict = None):
    params = params or {}
```

## Приоритет 3 — Производительность

### 3.1. Regex перекомпилируется при каждом вызове `_process_template_commands` и `_process_template_comments`

**Файл**: `gsconfig/template/classes.py:386,435`

Оба метода делают `re.compile(...)` каждый вызов. `_process_template_commands` вызывается рекурсивно (для `if` с `post_process=True`), и в цикле `while True` — потенциально десятки раз.

**Фикс**: Компилировать один раз в `__init__`:
```python
self._compiled_comment_pattern = re.compile(RE_COMMENT_PATTERN, re.DOTALL)
self._compiled_command_pattern = re.compile(RE_TEMPLATE_COMMAND_PATTERN, re.DOTALL)
```

И использовать `self._compiled_*` в методах.

### 3.2. `get_all_brackets()` пересоздаётся при каждом вызове `define_split_points()`

**Файл**: `gsconfig/gsparser.py:17-29,43`

`get_all_brackets` обходит все params и строит словарь скобок. Вызывается для каждой строки при каждом split. Params не меняются — результат всегда один.

**Фикс**: Кешировать brackets в `BlockParser.__init__`:
```python
class BlockParser:
    def __init__(self, params):
        self.params = params
        self._brackets = self._get_brackets()
        # ...

    def _get_brackets(self):
        brackets = {}
        for key, value in self.params.items():
            if key.startswith('br_'):
                brackets[value[0]] = 1
                brackets[value[-1]] = -1
        return brackets
```

Передавать `self._brackets` вместо `get_all_brackets(**params)` в `define_split_points`.

for line in data:

## Приоритет 4 — Качество кода

### 4.1. `GameConfigLite` не вызывает `super().__init__()`

**Файл**: `gsconfig/gsconfig.py:316-349`

Наследует `Document`, но не вызывает `Document.__init__(spreadsheet)`. Устанавливает атрибуты `page_skip_letters`, `key_skip_letters`, `parser_version` напрямую, дублируя логику `Document.__init__`. Если в `Document` добавится новая инициализация, `GameConfigLite` её не получит.

**Фикс**: Вызвать `super().__init__(spreadsheet)` после получения spreadsheet:

```python
class GameConfigLite(Document):
    def __init__(self, spreadsheet_id, client=None, params=None):
        params = params or {}
        self.client = client
        self.spreadsheet_id = spreadsheet_id
        self._cached_spreadsheet = None

        # Инициализируем Document с placeholder, переопределим spreadsheet через property
        super().__init__(None)
        self.page_skip_letters = params.get('page_skip_letters', {'#', '.'})
        self.key_skip_letters = params.get('key_skip_letters', {'#', '.'})
        self.parser_version = params.get('parser_version', 'v1')
```

**Проблема**: `Document.__init__` ожидает `spreadsheet` и сохраняет его как `self.spreadsheet`. Но `GameConfigLite` переопределяет `spreadsheet` через `@property`. Если передать `None` в `super().__init__()`, то `self.spreadsheet = None` будет затенено property.

Альтернатива: не вызывать super, но вынести общую инициализацию в миксин/метод:

```python
def _init_common(self, params):
    params = params or {}
    self.page_skip_letters = params.get('page_skip_letters', {'#', '.'})
    self.key_skip_letters = params.get('key_skip_letters', {'#', '.'})
    self.parser_version = params.get('parser_version', 'v1')
```

Вызывать из `Document.__init__`, `GameConfigLite.__init__` и `GameConfig.__init__`.

### 4.2. `Page.__repr__` вызывает `self.get()` — побочный эффект

**Файл**: `gsconfig/gsconfig.py:118-119`

```python
def __repr__(self):
    return json.dumps(self.get(), ensure_ascii=False)
```

`__repr__` может вызываться при логировании, отладке, в REPL. `self.get()` может триггерить сетевой запрос к Google Sheets API. Это побочный эффект в методе, который по конвенции не должен иметь сайд-эффектов.

**Фикс**: Упростить repr без сетевых запросов:
```python
def __repr__(self):
    return f"<Page '{self.title}' format={self.format}>"
```
